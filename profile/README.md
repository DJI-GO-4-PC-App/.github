DJI GO 4 is a drone flight control application for Windows that pairs with compatible DJI drones to show live video and flight data on one screen. It's sometimes searched under slightly different phrasing, like dji 4 go app, but it's the same DJI flight control interface either way.

> **Tip:** Keep DJI GO 4 itself and your drone's firmware on their current versions for the smoothest connection.

## Overview
DJI GO 4 gives pilots a full-screen view of their drone's live camera feed and flight telemetry, plus the camera controls needed to adjust shots mid-flight.

## Features
- [x] Live HD video feed from the connected drone
- [x] On-screen flight telemetry — altitude, speed, and battery
- [x] Mid-flight camera adjustments, including exposure and ISO
- [x] Intelligent flight modes for tracking and automated shots

## Requirements
→ OS: Windows 10, 64-bit or later
→ Hardware: A modern 64-bit processor, adequate RAM for smooth video, and free storage for the app and any saved footage

## FAQ
**Is DJI GO 4 free?** Yes, it's free to download and use with a compatible DJI drone. **Is DJI GO 4 the same as DJI Fly?** No — DJI Fly is a separate DJI application built for a different, newer set of drone models, while DJI GO 4 supports its own lineup of compatible aircraft; searches for dji go fly 4 usually mean one or the other, so it's worth checking which drone model you have. **Do I need a DJI drone to use it?** Yes, most of the app's features require a compatible DJI aircraft connected.

**License:** DJI GO 4 is free, proprietary software published by DJI, not open-source.
